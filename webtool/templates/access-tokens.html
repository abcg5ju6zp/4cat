Create one token per script or integration: each token has its own name, operation scopes, dataset boundary and expiry, and can be rotated or revoked without affecting your other integrations. Using a token

Tokens can be passed to API calls in two ways; via a GET parameter, access-token:

/api/endpoint?access-token=[token]

Alternatively, you can pass it as a request header, Authentication:

headers = {"Authentication": "[token]"}

The legacy Authorization header is accepted as well. You can also still get the legacy token programmatically via /api/request-token/ while logged in.
